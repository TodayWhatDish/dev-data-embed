# **프로젝트 명** : 우리 뭐먹냥

## **서비스 목적** : 반려견을 키우는 사용자를 위한 애완견 물품,간식,명소 AI 추천 서비스

​

## **주요 타겟** : 반려견을 키우는 사용자, 플랫폼을 통해 애완물품을 홍보하고자 하는 업체

​

## **필요데이터**

    - **제품, 간식 추천용 데이터** : 견종, 나이, 성별, 체중, 체형(급여량), 중성화여부(칼로리 영향), 알러지, 급여목적(관절,다이어트,피부), 식성, 선호형태(건식,습식), 예산

    - **명소 추천 데이터** : 위치, 동반가능여부, 견종크기, 장소유형(카페,음식점,공원,병원 등), 편의시설

    - **정보 분석 및 학습용 데이터** : 후기날짜, 리뷰내용, 평점, 구매여부, 재구매여부, 알러지 반응 여부

    - **LLM 응답 데이터**

        - 제품 및 간식 : 제품명, 가격, 선호형태, 추천이유, 구매평 요약, 알러지 안전 여부

        - 명소 : 장소명, 지역, 동반가능여부, 반려견사이즈,추천이유, 이용팁

​

**고민사항** : 결제 (B2B vs B2C)

**예시 프로세스**

입력(사용자 → LLM): 견종, 나이, 체중, 알러지, 급여목적, 식성, 위치, 추천목적

출력(LLM → 사용자): 추천 제품/명소 + 이유 + 안전 정보 + 가격/위치
